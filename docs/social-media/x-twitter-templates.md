## カテゴリ C: Tips・教育コンテンツ（週1回）

### C-1
フリーランスが月末に後悔しないための習慣:

1. 案件完了したら即売上記録（記憶が鮮明なうちに）
2. 請求書送付後に入金予定日をカレンダーに入れる
3. 月初に先月の売上を確認する
4. 四半期に一度、クライアント別収益を見直す

これ全部 FreelanceOS でできます。

#フリーランス #個人事業主 #案件管理

### C-2
freee と FreelanceOS の使い分け:

freee → 確定申告・会計処理
FreelanceOS → 日常の事業管理・売上追跡

「freeeの前に、まずFreelanceOS」

FreelanceOS でまとめたデータを
CSV でfreeeに渡すだけで確定申告の準備完了
